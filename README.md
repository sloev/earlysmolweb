# Early Smol Web

A collaborative, source-led research project documenting the earliest discoverable internet activity associated with every country and separately tracked territory.

We investigate more than the World Wide Web: connectivity, email, mailing lists, Usenet, UUCP, BITNET/EARN, FTP, Gopher, Telnet, IRC, internet-connected BBS/FidoNet systems, online publications, communities, databases, and personal websites.

**Explore the findings:** https://sloev.github.io/earlysmolweb/

## Research principles

- **Evidence before claims.** Every finding should link to sources and identify its evidence strength.
- **Keep milestones distinct.** DNS delegation, first connectivity, first email, first public service, first website, and first personal homepage are different claims.
- **Qualify “earliest”.** We document the earliest well-supported example currently found; we do not claim that no earlier activity existed.
- **Worldwide scope.** All 195 baseline countries are in scope, alongside separately tracked research jurisdictions.
- **Preserve uncertainty.** Leads, candidates, probable findings, and verified findings must not be conflated.

## Browse the project

- Research findings — country and territory research notes in research/.
- Working method — scope, evidence standards, record format, and research ethics.
- Country register — coverage and flexible discovery priorities.
- Public research website — searchable presentation generated from the research files.

The website reads the current Markdown research files from the public main branch whenever a visitor opens the page. New files and edits therefore appear automatically on the next page load; there is no second hand-maintained dataset or publishing workflow. GitHub Pages serves the page from main /docs.

## Contributing

Read CONTRIBUTING.md and WORK_METHOD.md before adding or editing research. Use the standard candidate record, cite primary and contemporary sources where possible, and make uncertainty explicit.

## Scope and limitations

This is an evolving research compendium, not a definitive census of firsts. Archive coverage is uneven across countries, languages, media, and periods. A missing result means that no earlier example has yet been located in the sources searched—not that none existed.
