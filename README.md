# Early Smol Web

A collaborative research compendium of the earliest personal websites, homepages, web diaries, personal web rings, and other individual internet expressions in every country and territory.

**Start here:** [WORK_METHOD.md](WORK_METHOD.md) · [coop.log.md](coop.log.md) · [COUNTRIES.md](COUNTRIES.md)

We run two tracks in parallel:
1. **Leads:** discover people, pages, archives, directories, communities, and historical sources.
2. **Evidence & records:** verify candidates, preserve evidence, and write consistent country entries.

The project is exploratory. "Earliest" means the earliest well-supported personal expression we can currently document, not a claim that no earlier one existed.
